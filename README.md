# 林王家族誌｜THE LIN × WANG FAMILY ARCHIVE

> **以年編事，以人立傳。** 林氏與王氏家族專屬網站。

## 網站定位

本站僅記錄林家與王家的家族史、家族通紀、人物列傳、世系關係、史料來源與典藏原則；並非《和平島誌》地方史網站。

主要架構：
1. **序章** — 家族敘事、網站理念與篇章入口。
2. **家族通紀** — 以編年體記錄家族大事；每卷包含時代背景、事件、資料來源狀態。
3. **人物列傳** — 以紀傳體保存人物經歷，與通紀交互連結。
4. **世系圖** — 公開版採匿名世代示意；詳細親屬關係保留於家族私人版本。
5. **典藏室** — 資料來源、查證狀態及家族記憶的保存原則。

## 公開版與私人版

本 GitHub 儲存庫目前是 **Public**。因此此處僅部署**去識別化的公開展示版本**，不包含在世人物的完整姓名、生日、學歷、私人 FB、醫療紀錄、精確安置資訊或完整血緣關係。

完整私人家族版另行保存於家族成員自行管理的備份檔，不得直接提交至本公開儲存庫；**切勿只靠前端密碼或隱藏按鈕保護私人資料**，因為公開原始碼仍然可讀。

## 編纂原則

- 事件與人物交互連結，以「編年體 × 紀傳體」呈現。
- 以原始文件、正式登記、家族口述、網站自述等分級標明來源。
- 無證據的日期、軍階、學歷及世代關係不直接作為定論。
- 口述應保留其原始語境；更正時保留修訂軌跡。
- 農曆生日需區分實際生辰與慶祝日期。
- 離世親屬與在世親屬的資料公開權限分開處理。
