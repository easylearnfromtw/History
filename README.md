# 林王家族誌｜The Lin × Wang Family Archive

林家與王家的專門族譜網站，收錄世系、人物傳記、家族大事紀與史料整理。

採用**編年體 × 紀傳體**的敘事架構：「家族通紀」記錄年代與事件，「人物列傳」敘述每個人的故事，再以家族樹、典藏室互相連結。

目前 GitHub main 分支是公開展示首頁，含詳細人物資料的完整家族版尚未部署。和平島地方史另案規劃，不屬於此族譜專站。

如要使用完整家族版，請使用另行提供的私人 ZIP。公開儲存庫可能被搜尋、複製與下載，刪除檔案也不保證清除已流傳的副本。

建議後續先在 Settings → General → Danger Zone → Change repository visibility 調整為 Private，再規劃家人可用的登入與權限機制。

資料應區分家屬口述、網站自述、官方文件與待查證紀錄，不能任意推測軍階、畢業資格或尚不明確的血緣關係。
